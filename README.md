# Aahil Dawoodani — personal website

Static site (HTML, CSS, vanilla JS). No build step.

- `index.html`: page structure
- `styles.css`: theme tokens at the top (`:root`), from the shared Theme & Color Palette
- `script.js`: theme toggle, photo table, lightbox, small extras
- `images/photos/`: web-sized photos (`large/` holds the lightbox versions)

Run locally: `python3 -m http.server 8765`, then open http://localhost:8765

Fonts: Jost (display), Roboto (body), JetBrains Mono (labels), loaded from Google Fonts.
